# VOICE BOX server

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/wcoconut-design/voice-reviewcard/tree/main/vb-server)

VOICE BOX 앱의 **정보 채우기**(판매 링크 → 작품 정보)와 **기기 간 동기화**에 쓰는 개인 서버예요.
버튼을 누르면 내 Cloudflare 계정에 서버와 저장소가 만들어져요. 배포 화면의 `VB_KEY` 칸에 앱에서 만든 열쇠를 붙여넣으세요.

Your own server for VOICE BOX (info fill + device sync). Paste the key from the app into `VB_KEY` when deploying.

VOICE BOX の情報取得と端末間同期のための個人サーバーです。デプロイ時に `VB_KEY` にアプリで作ったキーを貼り付けてください。

- 기록은 내 계정의 저장소에만 남아요. / Your data stays in your own account.
- 무료 요금제로 충분해요. / The free plan is enough.
